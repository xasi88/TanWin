# Озвучка букв и слогов

197 файлов: `<id>.mp3` — название буквы; `<id>-a.mp3`, `<id>-i.mp3`, `<id>-u.mp3` — буква с фатхой, касрой и даммой, чтец читает слог по складам («ба — фатха — ба»); `<id>-a.s.mp3` и так далее — один этот слог, вырезанный из той же записи
(`id` — как в `js/letters.js`; `hamza-a|i|u` — хамза на алифе: أَ إِ أُ; у алифа — только название).

**Источник (с версии 1.24.0).** Записи букваря «Каида Нурания» из репозитория <https://github.com/ibr7h/al-qaida-nooraniyya>
(сайт <https://ibr7h.github.io/al-qaida-nooraniyya/>): урок 1 — названия букв, урок 4 — буквы с огласовками.
Скачивает их `tools/audio/fetch-qaida.mjs`, обрабатывает `tools/audio/build.mjs`: обрезка тишины, выравнивание громкости, моно 64 кбит/с.

**Что изменено.** Записи слогов взяты целиком (с версии 1.24.1): так слог слышно ясно. Для сложения слогов в слово нужен слог без проговаривания:
`fetch-qaida.mjs` находит на записи последний всплеск громкости и вырезает его в файл `.s.mp3`. Названия букв взяты без изменений.

**Ошибка в описании источника.** У слога بَ там указан файл `f4-131` — это запись «وَ وِ وُ» предыдущей буквы; верный файл — `f4-132`.
`fetch-qaida.mjs` это исправляет сам. В версии 1.24.0 из-за этого слог «ба» звучал неверно.

**Разрешение.** В репозитории-источнике лицензия и имя чтеца не указаны. Автор TanWin прослушал записи и решил использовать их
со ссылкой на источник (9 октября 2026); ссылка стоит в приложении: «Ещё» → «Об источниках».

**До версии 1.24.0** здесь лежали записи из <https://github.com/bubblesinarabic/alphabets-audio>. Их заменили: диктор читал тяжёлые буквы
через «а» («ра» вместо «ро»). Чтобы заменить озвучку, достаточно положить в эту папку файлы с теми же именами.
