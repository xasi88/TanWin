**Что это.** Основное приложение: уроки чтения, практика, прогресс, настройки — и раздел «Мой Коран» с закладками.

На карте пока описаны только «Мой Коран» и закладки (проба). Уроки, «Практика», «Прогресс» и «Ещё» на карту ещё не занесены.

## Чем отличается от отдельного «Моего Корана»

- В меню шесть вкладок: Путь, Практика, Мой Коран, Закладки, Прогресс, Ещё — см. [[Меню приложения]].
- При первом запуске — знакомство с курсом.
- Есть экран «Ещё»: тема, обращение, чтец, копия данных, выключатель статистики. В отдельном приложении его нет — см. [[Чего нет в отдельном приложении]].
- Есть экран «Прогресс» со статистикой чтения Корана — см. [[Учёт чтения]].
- В «Ещё» есть ссылка «Установить „Мой Коран“ отдельно» — см. [[Установка Моего Корана]].

Сам «Мой Коран», чтение, закладки и цели в обоих приложениях — один и тот же код. Данные тоже общие — см. [[Общие данные с TanWin]].
