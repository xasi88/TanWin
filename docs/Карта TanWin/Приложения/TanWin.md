## Стоит знать

- В меню шесть вкладок: Путь, Практика, Мой Коран, Закладки, Прогресс, Ещё — см. [[Меню приложения]].
- При первом запуске — знакомство с курсом.
- В версиях 1.22.0–1.22.1 «Мой Коран» был ещё и отдельным приложением со своим значком (адрес /quran/). С версии 1.23.0 его нет: «Мой Коран» — только раздел TanWin. Старый адрес /quran/ открывает этот раздел; закладки, цели и место чтения остались на месте — хранилище то же.
- Код отдельного приложения сохранён на GitHub в ветке `quran-app-archive` — на случай, если из него когда-нибудь вырастет самостоятельный проект. В TanWin к нему не возвращаемся.
