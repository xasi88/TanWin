**Что это.** Вход в чтение Корана: откуда продолжить, джузы и все суры. У экрана три вида по одному адресу: главный, «30 джузов» и «Джуз N». Какой вид открыт, приложение помнит до перезапуска.

## Как сюда попадают

- Вкладка «Мой Коран» в меню.
- Из чтения: плитка «Назад в „Мой Коран“», клавиша Esc, выход из полного экрана.
- Старый адрес отдельного «Моего Корана» (/quran/) открывает этот экран — см. [[TanWin]].
- Ещё: кнопка «Открыть мусхаф» на «Пути», когда курс пройден.

## Что на экране

- Заголовок «Мой Коран» и строка «Мусхаф Мадины, риваят Хафса от Асыма. Выберите суру или джуз — текст откроется на весь экран».
- Карточка «Продолжить чтение Корана» — если читатель уже открывал чтение → [[Продолжить чтение]]
- Карточка «30 джузов» → [[Джузы]]
- «Все суры» — 114 строк, у прочитанных галочка → [[Список сур]], [[Отметка о прочитанной суре]]
- Ручка у правого края списка сур → [[Быстрая прокрутка списка сур]]
- Вид «30 джузов»: кнопка «‹ Мой Коран» и 30 строк «Джуз N» → [[Джузы]]
- Вид «Джуз N»: кнопка «‹ 30 джузов», кнопка «Читать джуз N целиком» и суры этого джуза → [[Джузы]], [[Список сур]]
- Нажатие на суру, джуз или карточку «Продолжить» разворачивает приложение на весь экран → [[Полный экран]]
- Кнопка «Написать разработчику» — здесь у левого края: справа ручка списка → [[Написать разработчику]]
- Один раз здесь может появиться окно «Приложение обновляется само» → [[Окно про обновления и VPN]]
- Список сур открывается и без интернета → [[Работа без интернета]]
- Меню приложения: снизу на телефоне, слева на широком экране — см. [[Меню приложения]]

## Робот

- состояние `закладки`
- открыть `#/quran`
- есть `.my-quran h1`
- есть `a.reading-card` — «Продолжить чтение Корана»
- есть `button.mq-juz` — карточка «30 джузов»
- есть `.surah-list a.surah-row >> nth=113` — все 114 сур
- есть `.surah-row .sr-done` — галочка у прочитанной суры
- есть `.sura-scrub .ss-thumb` — ручка списка
- есть `.fb-tab` — «Написать разработчику»
- нажать `button.mq-juz`
- есть `button.juz-row >> nth=29` — 30 джузов
- есть `button.mq-back`
- нажать `button.juz-row >> nth=0`
- есть `a.btn.primary >> text=/Читать джуз 1 целиком/`
- есть `.surah-list a.surah-row`
- есть `button.mq-back`
- открыть `quran/` — старый адрес отдельного «Моего Корана»
- есть `.my-quran h1`
- есть `#nav .tab >> nth=5` — открылся TanWin со всеми вкладками
