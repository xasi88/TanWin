**Что это.** История изменений приложения и кнопка проверки обновления.

## Как сюда попадают

- «Ещё» → «О приложении» → «Версии».
- На широком экране — строка «Версия … · в разработке» внизу меню.

## Что на экране

- Ссылка назад «‹ Ещё».
- «Сейчас у вас версия …» и пояснение про обновления и VPN; кнопка «Проверить обновление» → [[Проверка обновления]]
- Плашка «Приложение в активной разработке» с кнопкой сообщения автору → [[Написать разработчику]]
- Список версий: номер, название, дата, что изменилось; у первой — «текущая».
- Один раз здесь может появиться окно «Приложение обновляется само» → [[Окно про обновления и VPN]]

## Для разработки

Код:
- `js/views/changelog.js` · `export function ChangelogView`
- `js/app.js` · `m.ChangelogView()`

Проверка:
- `tools/audit/start-check.mjs` · `в «Версиях» есть «Проверить обновление» и возврат в «Ещё»`

Вёрстку смотрит бот:
- `tools/audit/audit.mjs` · `"/changelog"`
