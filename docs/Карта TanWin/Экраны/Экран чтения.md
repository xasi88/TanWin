**Что это.** Текст Корана на весь экран. Один экран для суры и для джуза целиком. Страница мусхафа и цель закладки — его разновидности: [[Страница мусхафа]], [[Экран цели закладки]]. При открытии на экране только текст.

## Как сюда попадают

- Строка суры в «Моём Коране» (адрес #/read/N; из джуза — #/read/N/A, с аята начала джуза).
- Кнопка «Читать джуз N целиком» (#/juz/J).
- Карточка «Продолжить чтение Корана» (#/read без номера открывает последнее место).
- Закладка без цели — чтение суры с её аята.
- В TanWin ещё: «Открыть в мусхафе» у суры на «Пути», прочитанные суры в «Прогрессе». Старые адреса вида #/quran/2/255 тоже открывают чтение.

## Что на экране

- Текст: название суры, «Бисмиллях», аяты с номерами; между страницами — отметки «страница N · джуз M» → [[Вид текста]], [[Чтение по страницам]]
- Тонкая полоса у верхнего края — доля прочитанного; нажатие на экран показывает и прячет панели → [[Панели чтения]]
- Вверху всегда: 30 точек-джузов с подписью → [[Дорожная карта джузов]]
- Верхняя панель, первая строка: «Сура … · аят N из M · стр. P · джуз J» → [[Панели чтения]]
- Плитка «Назад в „Мой Коран“» → [[Выход из чтения]]
- Плитка «Слушать суру» / «Продолжить с аята N» / «Остановить чтеца»; нажатие на номер аята и на «Бисмиллях» → [[Чтец]]
- Плитки «Суры», «Пред. сура», «След. сура»; в конце текста — «Дальше: сура …» или «Конец Корана» → [[Переход между сурами]]
- Плитка «Страница, джуз» → [[Переход к странице и джузу]]
- Плитка «Закладка здесь» → [[Поставить закладку]]
- Плитка «Закладки: N» — открывает [[Окно закладок]]
- Плитки «Чтец: Хусари / Афаси», «Темп чтеца: 1×», «Повтор аята: ×1» → [[Настройки чтеца]]
- Плитки «Сплошной текст» и «По аятам, с переводом» → [[Вид текста]]
- Плитка «По страницам» → [[Чтение по страницам]]
- Плитка «Скрыть слова: нет» → [[Скрыть слова]]
- Плитка «Цвета таджвида» → [[Цвета таджвида]]
- Плитка «Сура прочитана» → [[Отметка о прочитанной суре]]
- Плитка «Скачать аудио суры» → [[Аудио без интернета]]
- Нижняя панель: пуск и пауза, «−», скорость, «+» → [[Автопрокрутка]]
- Нижняя панель: кнопка «Aa» — открывает [[Панель Aa]] → [[Размер текста и шрифт]]
- Справа: полоска с номерами страниц → [[Колесо страниц]]
- Долгое нажатие на слово — открывает [[Окно слова]] → [[Карточка слова]]
- При чтении джуза: под точками-джузами «Читаем джуз N целиком · до конца M страниц», в конце — «Джуз N прочитан» и «Дальше: джуз N+1» → [[Джузы]]
- Кнопка «Написать разработчику» — у левого края, видна только при открытых панелях → [[Написать разработчику]]
- Не видно глазами, но работает всё время: место чтения запоминается → [[Продолжить чтение]]; страницы и время считаются → [[Учёт чтения]]; экран не гаснет → [[Экран не гаснет]]; приложение развёрнуто → [[Полный экран]]
- Суры, которые уже открывали, читаются и без интернета → [[Работа без интернета]]

## Стоит знать

- Плитки верхней панели идут в таком порядке: Назад в «Мой Коран» · Слушать суру · Суры · Страница, джуз · Пред. сура · След. сура · Закладка здесь · Закладки · Чтец · Темп чтеца · Повтор аята · Сплошной текст · По аятам, с переводом · По страницам · Скрыть слова · Цвета таджвида · Сура прочитана · Скачать аудио суры.
- Меню приложения на этом экране скрыто.
- Функции в верхней и нижней панелях не повторяются.

## В отдельном приложении «Мой Коран»

Тот же экран, те же 18 плиток (проверено в браузере). Отличается только поведение кнопки «Подробно о правилах» в окне цветов таджвида — см. [[Цвета таджвида]].
