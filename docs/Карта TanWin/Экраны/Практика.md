**Что это.** Десять карточек: повторение того, что пора освежить, трудные слова и восемь тренажёров.

## Как сюда попадают

- Вкладка «Практика» в меню.

## Что на экране

- Заголовок и пояснение про интервальное повторение.
- Первая карточка — «Повторение»: сколько тем ждёт, красный кружок с числом → [[Повторение пройденного]]
- «Трудные слова» — открыта, когда такие слова есть → [[Трудные слова]]
- Тренажёры: Буквы, Тренажёр слуха, Махраджи, Беглое чтение, Слова на слух, Мой голос, Найди правило, Сколько тянуть? — закрытые с замком → [[Тренажёры]]

## Робот

- открыть `#/review`
- есть `a.drill.main` — «Повторение»
- есть `a.drill.main .badge` — сколько тем ждёт
- есть `.drills .drill >> nth=9` — десять карточек
- есть `.drill.locked` — закрытый тренажёр
- есть `#nav .tab.on >> text="Практика"`
