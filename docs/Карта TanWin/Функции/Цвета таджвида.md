**Что видит человек.** Буквы раскрашены по правилам таджвида. Плитка «Цвета таджвида» открывает расшифровку: цвет, название правила, короткое объяснение. Цвета выключаются переключателем в панели «Aa».

## Правила

- Сначала цвета включены.
- Переключение мгновенное, без перезагрузки текста.
- В карточке слова цвета показаны всегда — даже когда в тексте выключены.
- Внизу расшифровки — кнопка «Подробно о правилах»: ведёт в справочник правил; окно расшифровки при этом закрывается.
- Так устроены все окна приложения: переход на другой экран закрывает открытое окно.
- Переключатель цветов есть ещё в «Ещё» → «Вид».
