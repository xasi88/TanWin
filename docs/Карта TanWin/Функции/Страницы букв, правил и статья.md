**Что видит человек.** У сайта есть обычные страницы, которые находит поиск: по одной на каждую букву, на каждую тему таджвида и статья «Как научиться читать Коран с нуля». С каждой — кнопка в приложение.

## Правила

- Страницы пишутся не руками: при каждой сборке они заново создаются из тех же данных, что и уроки. Изменили урок — изменилась страница.
- Статья — единственная страница с отдельно написанным текстом.
- Кнопки «Открыть приложение», «Начать учиться», «Учить эту букву в приложении», «Открыть урок в приложении». Нажатие на них попадает в статистику.
- У урока с теорией должен быть задан адрес страницы, иначе сборка остановится. Уже существующие адреса менять нельзя.
- Карта сайта пересобирается вместе со страницами.
- У главной страницы, списка букв, списка правил и статьи скрытые заголовок и описание для поисковиков составлены из слов, которые люди набирают в поиске («с нуля», «самостоятельно», «для начинающих», «бесплатно», «онлайн»). На самих страницах этот текст не виден. Слова собраны из подсказок Яндекса и Google 10 октября 2026.
- Приложение эти страницы не кэширует; без интернета вместо них открывается само приложение.
