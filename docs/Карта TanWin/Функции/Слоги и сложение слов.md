**Что видит человек.** Буква с огласовкой — это слог; слог плюс слог — слово. Слоги показаны плитками: нажал — услышал. В карточке «Слог + слог = слово» плитки складываются в настоящее слово Корана.

## Правила

- Три плитки буквы: с фатхой, касрой и даммой. Под каждой три слова записи: имя буквы, имя огласовки, слог → [[Подписи к записи слога]]
- В карточке сложения: слоги справа налево, под ними слитное слово. Нажатие на слово проигрывает каждый слог по складам, потом слово целиком голосом чтеца.
- Нет записи слова (цепочка слогов): слоги звучат по складам, потом плитка слитного чтения светится, а читает её сам ученик. Слитной записи цепочки нет.
- Примеры — настоящие слова Корана из одних открытых слогов и только из уже пройденных букв. Пока букв мало, вместо слов — цепочки слогов.
- Упражнение «Соберите слово из слогов»: плитки внизу, слово собирается сверху, буквы соединяются по мере сборки; есть лишние плитки и кнопка «Убрать слог».
- У алифа слогов нет: своего согласного звука у него нет.
