**Что видит человек.** Узкая полоска справа с номерами всех 604 страниц; начала джузов выделены. Пока её крутят, рядом видно «Страница N · джуз · сура». Отпустили — открывается эта страница.

## Правила

- Медленное движение пальца — страница за страницей.
- Быстрый взмах — колесо разгоняется и летит дальше: до любого конца Корана пара жестов.
- Нажатие на номер — сразу к этой странице. Нажатие по летящему колесу — остановить его.
- Колесо мыши тоже крутит полоску.
- Колесо само показывает страницу, на которой читатель сейчас.
- Видно только при открытых панелях. Само панели не открывает и не прячет.
- Переход по колесу останавливает чтеца.
