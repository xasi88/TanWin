**Что видит человек.** Чтение идёт на весь экран — без адресной строки и панелей браузера.

## Правила

- Установленное приложение и так открывается отдельным окном без адресной строки.
- Во вкладке браузера страница разворачивается по нажатию на суру, джуз, закладку или карточку «Продолжить»: браузеры разрешают это только по нажатию.
- Настройка «Полный экран»: пока её не трогали, она включена на телефонах и планшетах, открытых в браузере. Включена — любое нажатие возвращает полный экран.
- Кнопка «На весь экран» / «Выйти из полного экрана» — в меню, только на широком экране.
- Выход из полного экрана во время чтения закрывает чтение.
- iPhone полный экран для страниц не поддерживает: там только установка на экран «Домой».
- В TanWin есть ещё переключатель «Полный экран» в «Ещё» → «Вид».

## В отдельном приложении «Мой Коран»

Кнопка в меню та же. Переключателя нет: нет экрана «Ещё». На телефоне в отдельном приложении включить или выключить полный экран негде.
