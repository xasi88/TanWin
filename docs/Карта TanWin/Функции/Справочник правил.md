**Что видит человек.** Карточка правила таджвида: цвет, название, короткое и полное объяснение и четыре примера из Корана, которые звучат по нажатию.

## Правила

- В справочнике правила собраны по группам; цвета те же, что в мусхафе приложения.
- В примерах раскрашено только то правило, о котором карточка.
- Примеры каждый раз подбираются заново из 38 сур пути; для редких правил — со всего Корана.
- Та же карточка показывается в уроках таджвида.
- Изхар — ясное чтение — цветом не отмечается.
