# TanWin — путь к чтению Корана

**Открыть приложение:** https://xasi88.github.io/TanWin/ · Проектная документация: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

Интерактивная платформа, на которой человек, не знающий арабского, проходит путь от первой буквы до чтения мусхафа по правилам таджвида (риваят Хафса от Асыма). Статическое PWA: без сервера, базы данных и регистрации, работает на телефоне, планшете и компьютере, в том числе офлайн. Устанавливается как отдельное приложение: кнопка «Установить приложение» в меню (Chrome, Edge, Яндекс Браузер; на iPhone — «Поделиться → На экран „Домой“»).

## Методика

Порядок — классическая «Каида Нураниййа», затем таджвид и чтение сур:

| Этап | Содержание |
|---|---|
| 1. Первые шаги | Письмо справа налево, буквы-согласные, огласовки, как учиться |
| 2. Алфавит | 28 букв + хамза: звук, форма, точки, слова Корана на каждую букву |
| 3. Махраджи | 5 областей и 17 точек выхода звуков (интерактивная схема), тяжёлые/лёгкие буквы, трудные пары на слух |
| 4. Буквы в словах | 4 формы, 6 несоединяемых букв, لا ة ى |
| 5. Харакаты | Фатха, касра, дамма; чтение настоящих слов Корана |
| 6. Танвин | ـً ـٍ ـٌ |
| 7. Долгие гласные | Мадд ا و ي, маленький алиф, сыла |
| 8. Сукун | Закрытые слоги, лин, калькаля |
| 9. Шадда | Удвоение, гунна |
| 10. Особые написания | Хамзат-уль-васль, лунные/солнечные буквы, имя Аллаха, немые буквы, мадда |
| 11. Нун и мим | Изхар, идгам, икляб, ихфа; три правила мим сакины |
| 12. Мадды | 2 · 4–5 · 2/4/6 · 6 харакатов, буквы муката'ат |
| 13. Звучание | Тяжёлая/лёгкая ра, калькаля, идгам близких букв |
| 14. Вакф | Как останавливаться, знаки остановки |
| 15. Читаем Коран | Аль-Фатиха и 37 сур Джуз Аммы: слушаем → находим правила → читаем за чтецом |

Принципы (подробно — в приложении, «Ещё → Методика»):

* **Только пройденное.** Слова для чтения — настоящие слова Корана, автоматически отобранные так, чтобы в них не было ещё не изученных знаков (декодируемые тексты). 6 189 слов разложены по уровням.
* **Живые чтецы.** Пословное аудио Quran.com, аяты — Махмуд аль-Хусари (обучающее чтение) и Мишари аль-Афаси, с подсветкой звучащего слова. Компьютерного синтеза нет.
* **Интервальные повторения** (Лейтнер: 1, 2, 4, 8… дней), активное припоминание, повтор ошибок в конце урока, проверка этапа на 80 % (обучение до мастерства), звук + образ.
* **Транскрипция — только опора**: скрыта до ответа; особые звуки выделены знаками и цветом (х̣ ʿ ҡ с̣ д̣ т̣ з̣ с̱ з̱ һ ғ ў).
* **Прогресс виден**: путь с узлами, звёзды, нур (опыт) и уровни, цель дня и серия, освоение каждой буквы и правила, награды.
* **Учитель обязателен** в конце пути (талакки) — приложение даёт основу, тонкости ставит чтец.

## Запуск

```bash
node tools/build.mjs
python -m http.server 8080
```

Откройте http://localhost:8080. Офлайн-режим (service worker) работает на `localhost` и `https`.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория) автоматически после `git push`. Перед коммитом выполните `node tools/build.mjs` (обновляет версию и список офлайн-файлов в `sw.js`). Подойдёт и любой другой статический хостинг с HTTPS.

## Данные

```bash
node tools/qdata/fetch.mjs      # слова, разметка таджвида, перевод Кулиева (Quran.com API v4)
node tools/qdata/fetch_seg.mjs  # тайминги слов для аудио аятов
node tools/qdata/build.mjs      # data/*.json
```

Источники: текст и разметка таджвида, пословное аудио и тайминги — Quran.com; аудио аятов — EveryAyah / Quran.com; перевод смыслов — Э. Кулиев (проверьте условия использования перевода перед публичной публикацией). Шрифты Amiri Quran и Nunito — SIL OFL.

## Ограничения

* Аудио загружается из интернета (Quran.com, EveryAyah); пословное аудио сохраняется для офлайна после первого прослушивания, аяты — по кнопке «Скачать аудио для офлайна» в читалке.
* Отдельных записей слогов («ба», «би», «бу») нет — авторитетного открытого источника не нашлось, а синтез голоса ошибается. Звуки букв даются через слова Корана в исполнении чтеца.
* Приложение не проверяет произношение ученика автоматически: есть запись голоса и сравнение с чтецом, но оценку даёт сам ученик (а в идеале — учитель).
* Прогресс хранится в браузере устройства; перенос — через файл («Ещё → Данные»).
